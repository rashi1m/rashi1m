## 🐞 Sample Bug Report (my format)

> This is an example of how I write defects. Real reports are in my project repos.

| Field | Example |
|---|---|
| **Bug ID** | BUG-001 |
| **Title** | Login succeeds with a blank password field |
| **Module** | Login |
| **Environment** | Chrome, Windows 11, Test build |
| **Steps to Reproduce** | 1. Open login page → 2. Enter a valid username → 3. Leave the password blank → 4. Click Login |
| **Expected Result** | Error message: "Password is required" |
| **Actual Result** | User is logged in |
| **Severity / Priority** | High / P1 |
| **Status** | New |
| **Attachment** | Screenshot / screen recording |
